# ecoevo-hmsc

Analysis of eco-evolutionary dynamics using JSDM

Pantel, Jelena H. and Hermann, Ruben J. 2025. Detection of eco-evolutionary dynamics in communities using Joint Species Distribution Models. [https://doi.org/10.1101/2024.11.30.626152](https://doi.org/10.1101/2024.11.30.626152)

## Description

This repository contains the software to simulate eco-evolutionary dynamics in metacommunities, and to analyze the impact of trait evolution (or any trait change) for population and community abundances. The repository has code, data files and figures generated by code, and walk-through appendices to accompany the manuscript [Pantel & Hermann 2025](https://doi.org/10.1101/2024.11.30.626152). We use a joint species distribution model (JSDM), namely HMSC (Hierarchical Modelling of Species Communities), to estimate the importance of phenotypic evolution for species abundances in populations, communities, and metacommunities.

### Installing

* The output folder contains raw versions for all figures in the manuscript Pantel & Hermann 2025. Some of these will be overwritten if the code to create the figures (/code/R/figX.R, /code/R/figs_A4.R, /code/R/figure_box1.R) is executed.
* The data folder contains files output in one part of the code that is used in subsequent parts. For example, init.RData is the initial metacommunity composition and trait values that are generated by the code 1_metacom_sim.R. The code sets random seeds, which will recreate all files in the folder data.

### Installation of ecoevoR package

The ecoevoR package is hosted on GitHub and can be installed using one of the following methods:

For standard installation:

```
# install.packages("pak")
pak::pak("jhpantel/ecoevoR")
```
Depending on yours download speed (the package is 700mb), you might need to run this:

```
# install.packages("R.rsp")
# options(timeout=10000) 
devtools::install_github("jhpantel/ecoevoR",build_vignettes=TRUE)
```


### Contents of repository

The four main folders in this repository are code, data, manuscript, and output. The files contained in the folders are listed here, and described below. The `code` folder contains all of the R code needed to reproduce results found in the manuscript Pantel & Hermann 2025.

```
- |code
- | |R
- | | |-1_metacom_sim.R
- | | |-2_results_sim.R
- | | |-3_main.R
- | | |-4_diagnostics.R
- | | |-5_results_hmsc.R
- | | |-6_emp_hmsc.R
- | | |-fig2.R
- | | |-fig3.R
- | | |-fig4.R
- | | |-figs_A4.R
- | | |-figure_box1.R
- | | |-plot_grad_ylim.R
- | | |-two_h_cust.R
```

* 1_metacom_sim.R - Runs the metacommunity simulation with 50 sites, 15 species, and varying heritability and dispersal levels. Results are saved in data/init.RData and data/mc.
* 2_results_sim.R - Metacommunity diversity summary statistics are calculated, and plots of the main dynamics over time for all 50 patches (abundances, trait values, population growth rates, etc). This is a general script that can be used with any set of metacommunity results that are saved in data/mc.
* 3_main.R - Code to run HMSC analysis on metacommunity simulation results.
* 4_diagnostics.R - Code to run diagnostic checks on HMSC metacommunity model results.
* 5_results_hmsc.R - Code to synthesize the results for HMSC analyses of metacommunity model results.
* 6_emp_hmsc.R - Code to prepare and run HMSC analysis on empirical data from Jewell & Bell 2023.
* All fig/figure code produce the raw ficure as described by the name of the file.
* plot_grad_ylim.R & two_h_cust.R - Modified plot code from the HMSC package, to adjust the plot for figure 2.


The `data` folder contains all data generated and used in our code (from the code/R folder), as well as the empirical data from Jewell & Bell 2023.

```
- |data
- | |emp
- | | |-hmsc_emp.RData.R
- | | |-Phase1_anundances.csv
- | | |-Phase1_phenotypes.csv
- | | |-ReciprocalTransplant.csv
- | |init.RData
- | |mc
```

* emp - Contains data files from Jewell & Bell 2023, as well as the results for an HMSC analysis on those files (produced by 6_emp_hmsc.R, note that results are overwritten if that code is run)
* init.RData - Saves the initial metacommunity state (produced by 1_metacom_sim.R) that was used for all metacommunity simulations included in Pantel & Hermann 2025.
* mc - Contains all metacommunity simulation time series produced by 1_metacom_sim.R (for all combinations of heritability and dispersal level) and the HMSC analyses for a subset of these (produced by 3_main.R) that are used to create Figure 3c in Pantel & Hermann 2025.


The `manuscript` folder contains the R Markdown .Rmd files that produced the appendices that accompany Pantel & Hermann 2025, as well as Box 1 in the main manuscript.

```
- |manuscript
- | |Appendix_S1.Rmd
- | |Appendix_S2.Rmd
- | |Appendix_S3.Rmd
- | |Appendix_S4.Rmd
- | |Appendix_S5.Rmd
- | |Box1.Rmd
```

The `output` folder contains the raw figures produced by figure code files in the R/code folder.

```
- |output

- | |fig_S4_1.pdf
- | |fig_S4_2.pdf
- | |fig_S4_3.pdf
- | |fig1.pdf
- | |fig2.pdf
- | |fig3.pdf
- | |fig4.pdf
```
